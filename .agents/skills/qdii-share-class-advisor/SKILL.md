# 场外 QDII 份额选择与额度决策

## 一、必须先核实的四个事实（不要靠记忆推）

1. **份额代码**——去基金公司官网的「基金经理管理产品列表」或转型/变更公告里找，那里有一张"代码 ↔ 份额简称"对照表。**不要去基金详情页猜。**
2. **费率**——晨星 `morningstar.cn/fund/<code>.html` 会自动列出同基金各份额的 管理费/托管费/销售服务费/综合费率，一次拿全。
3. **额度规则**——看基金公司公告原文（上证报 `paper.cnstock.com`、中证网），搜「调整大额申购(含日常申购和定期定额投资)及转换转入限制的公告」。
4. **赎回费档位与持有天数起算规则**——招募说明书 / 代销平台费率页。

### ⚠️ 代码推断的坑（踩过一次）

**A/C/E 不一定按 091/092/093/019118 顺序排列，美元份额会插在中间。**

实例：景顺长城纳斯达克科技ETF联接(QDII)
| 代码 | 份额 |
|---|---|
| 017091 | A 人民币 |
| **017092** | **A 美元现汇** ← 不是 C |
| 017093 | C 人民币 |
| 019118 | E 人民币 |

推导规则：`A人民币 → A美元现汇 → C人民币 → E人民币`。**遇到"某个代码看起来应该是 C 类"时，先验证再下结论**，否则会误导用户改错数据。

## 二、费率平衡点（A vs C vs E）

固定结构：管理费 0.80% + 托管费 0.20% + 约 0.59% 其他 ≈ **1.59%-1.79%-1.99%**（A / E / C，E 比 C 少 0.20% 销售服务费）。

平衡点公式（申购费按 1 折 0.12% 计）：

| 对比 | 平衡点 | 谁优 |
|---|---|---|
| A vs C | ≈ **3.6 个月** | 超过则 A 优 |
| A vs E | ≈ **7.2 个月** | 超过则 A 优 |
| C vs E | **任何持有期 C 都最差** | 永远选 E |

**C 类唯一的用途是超短线（< 3.6 个月）且金额小到赎回费差 > 申购费。实务上 C 类基本等于"永远不该新增"。**

### 三类份额完整费率（三个独立来源一致：基金公司官网 / 银行代销页 / 产品资料概要）

| 项目 | A（017091） | C（017093） | E（019118） |
|---|---|---|---|
| 管理费 / 年 | 0.80% | 0.80% | 0.80% |
| 托管费 / 年 | 0.20% | 0.20% | 0.20% |
| 销售服务费 / 年 | **0.00%** | **0.40%** | **0.20%** |
| 申购费（1 折后） | **0.12%**（原 1.20%） | 0 | 0 |
| 赎回费 < 7 日 | 1.50% | 1.50% | 1.50% |
| 赎回费 7–30 日 | 0.75% | 0.75% | **0** |
| 赎回费 30–180 日 | **0.50%** | **0.50%** | **0** |
| 赎回费 ≥ 180 日 | **0** | **0** | **0** |

### ⚠️ A 类也有 180 天赎回费门槛（最容易漏的一条）

**A 类的免赎回费门槛是 180 天，不是 7 天。三档里只有 E 类是 ≥7 天即免。**

这直接改写"选 A 还是选 E"的话术：

1. **"A 优于 E"的 7.2 个月平衡点，只对"确定持有 > 180 天"的钱成立。** 若 180 天内可能赎回，A 要同时付申购费 0.12% + 赎回费 0.5%（30–180 日档），**反而是三档里最差的**（E 在该区间两项都是 0）。
2. **推荐 A 类必须带前提**："确定半年以上不动"才选 A；否则选 E，哪怕 E 的销售服务费高 0.2%。
3. 给小额新买入（如 200 元）推荐 A 时，把这句话说清楚：**180 天内赎回要多付 0.5%（200 元 = 1 元），远超它在费率上的年度优势。**

## 三、赎回费 FIFO 重建（最容易算错的地方）

前提规则：
- 赎回费**按每笔份额各自持有天数**分别计算，不是按整个持仓
- 赎回默认**先进先出（FIFO）**——先买的先被赎回，不能指定
- 持有天数按**自然日**，自**申购确认日**起算（确认日通常 T+1/T+2，实际满 180 天要顺延 1–2 天）

**推导方法**：把该基金全部买入按时间排序 → 累加成本 → 用"某次卖出金额"去消耗最早的批次 → 剩下的就是当前持仓。**用当前市值反算：成本 = 市值 ÷ (1 + 收益率) 做校验**，如果反算成本与 FIFO 剩余对得上，重建成立。

**结论价值**：常见误区是"整个仓位都没满 180 天"。实际往往 80% 已满、只有最后一笔未满。**这会直接反转"要不要等"的结论**——例如成本 705 元里只有 100 元那笔差 18 天，赎回费约 0.6 元，那就别为 0.6 元赌窗口。

## 四、转换的两个隐藏规则

1. **持有期不延续**：同一基金不同份额间转换，**原持有期限不延续计算，转入份额的持有期自转入确认日重新起算**。→ 转换后 7 天内赎回要付 1.5%。
   - 所以：**打算长期持有 → 转换（换费率+流动性）；其实想减仓 → 不要转，直接赎回原份额**（旧份额已满 180 天时零成本）。
2. **失败会级联**：公告明确「转换转入确认失败的，原基金转换转出申请也将确认失败」。→ **同一天不要既做转换转入、又大额申购同一份额。**

## 五、额度窗口判断（回答"会不会被抢光"）

**核心认知：额度不是"被买光的池子"，是基金公司主动拧的阀门。**

分析三步：
1. **抽出同类先例的窗口时长**——搜近期"XX纳斯达克100 恢复申购 / 调整大额申购限额"新闻。先例常常是 **1–2 天**（调高后立刻降回），但也能持续 **9 天+**。**没有规律，所以不能拿"窗口很短"当加仓理由。**
2. **算清"额度占用"的叠加**——公告通常写「单日单个基金账户在**任意一类**基金份额上的累计申请金额 ≤ N 元」。**申购 + 定投 + 转换转入，同一份额三类相加**。所以"转换 + 申购同一份额"很容易超限。
3. **识别营销话术**——**基金公司自己会在代销平台发"稀缺额度"软文**（如景顺长城在东方财富发的《稀缺外汇额度扩容，您持有的纳指科技或迎布局窗口！》）。**这是销售材料，不是市场信号。** 看到"稀缺""窗口""最后机会"要主动标注来源是基金公司。

**该给用户的反驳框架（比讲费率有效）**：
> 额度紧迫感只会指向你**已经过度拥挤**的那一处。把它和用户的配置缺口放在一起对比——如果缺口最大的地方（通常是境内品种）没有额度限制，那"稀缺"就构不成加仓理由。

### 5.4 渠道限额导致的分批转换：停止点与"等待反转"

**现象**：代销渠道（支付宝/蚂蚁）常有比基金公司公告更严的单日限额，报错文案——

> 转出份额的预估金额大于转入基金的最大可买金额

这是**提交前校验拦截**，不是交易失败：转出份额不动、不产生费用。原因——基金转换 = 转出（赎回）+ **转入（申购）**，转入端要遵守转入份额的当日限额。**瓶颈在转入端，不在转出端。**

**停止点公式**：赎回走 FIFO，分批转出会**先消耗免费池**，所以

> 累计转出份额 ≤ 免费池份额 ⇒ 赎回费 = 0

**免费池一旦吃光，剩余份额全部落在最高费率档 —— 此时应当停手。**

**"要不要继续等"会随剩余规模反转。** 判据不是"等了多久"，而是把三笔钱都算出来：

| 情形 | 等待省下的赎回费 | 等待多付的服务费 | 若窗口关闭的年度损失 | 需窗口关闭多久才不划算 | 结论 |
|---|---|---|---|---|---|
| 大额待转（867 元，含免费池） | 0.64 元 | 0.10 元 | 1.73 元/年 | 约 3.8 个月 | **别等** |
| 小额剩余（79 元，全在 0.5% 档） | 0.40 元 | 0.01 元 | 0.16 元/年 | 约 2.4 年 | **等** |

**规律：待转金额越小，"卡在原份额"的年度惩罚越低（∝ 金额），而赎回费节省下降得更慢 → 小额剩余份额几乎总该等到满 180 天再转。** 不要沿用上一轮"别等"的结论，规模变了结论就变。

**报错信息的第二个用途**：把渠道显示的「剩余限额」+「今日已转出金额」相加，若 ≠ 公告限额 → **该渠道执行限额更严**，不要按公告数字做计划。

**四个禁止**：① 反复提交（校验拦截重试无意义，万一通过会造成重复申请）；② 用"先赎回再申购"绕（申购端受同样限额约束，绕不开还多几天离场时间）；③ 为"怕窗口关了"提前付赎回费（保险费 > 保额的负期望交易）；④ 沿用上一轮的"等/别等"结论而不重算（规模变了结论就变）。

**噪声底线判据（防止用户在几毛钱上过度消耗心力）**：若可优化的费用 < 该仓位**单日 ±1% 的净值波动**，明确告诉用户"到此停止优化"，不再给更细的方案。（例：79 元仓位日波动 ±0.79 元 > 可省 0.40 元。）这句话比再算一遍更有价值。

### 5.5 限额"收紧"公告的三层读法（别只读数字）

公告把额度从 1,000 降到 100 时，至少读出三件事：

1. **限额通常按"每一类份额"分别计算**，不是全类合计——公告表格会给 A/C/E 各列一个数字。所以"每类 100 元"实际等于 **A+C+E 合计约 300 元/天**。不要读成"一天只能买 100 元"。
2. **代销与直销是两个通道，常差数倍。** 实例（景顺长城纳指科技，2026-09-21 起）：代销 **100 元/天/类**，直销 **500 元/天/类** → 直销是代销的 **5 倍**。**听到"额度要关了"，第一反应该是查直销限额，而不是抢今天的额度。**
3. **收紧的原因常写在公告里，且方向与"抢购"相反。** 原文"为充分保护基金份额持有人利益，保障基金平稳运作" = 基金公司在说**资金进得太快对现有持有人不利**。对 QDII 联接基金尤其真实：新资金要按场内 ETF 的**溢价**买底层资产（例：159509 溢价 23–25%、多次停牌），被摊薄的正是存量持有人（含用户自己）。

**对用户的实际影响必须先算再答**：拿新额度与用户**常态单笔金额**比。若常态单笔 ≈ 新限额（例：常态 100–200 元 vs 新限 100 元/天），结论就是 **"对你的影响 ≈ 0"**——被砍掉的是"从未用过、且一直被劝少用"的额度。此时正确的回答是"**这不是没机会，是冲动空间被限住了**"，而不是帮他想怎么在最后一天打满。

**"最后一天打满"的破解方式**：算出打满后该主题桶的**剩余余量**。**"打满 = 一次性用光配置空间"** 这个数字比讲道理有力得多。

### 5.6 组合结构体检：区分"名义分散"与"实际集中"

> **相关的姊妹技能**：`portfolio-attribution-review`——当用户问的是"**今年为什么没赚到钱 / 是行情还是我的策略**"这类**全组合收益归因**问题时，加载那个技能。本节只解决"同一主题被买了 N 遍"的结构问题。

用户说"像开超市一样买了很多产品"时，**不要按基金名字归类**——海外 QDII 里"名字与持仓不符"是常态。方法：

**第一步：按实际持仓而非名字分簇。** 拉每只基金的定期报告前十大重仓股（来源优先级：基金公司官网季报 PDF > 天天基金 `fundf10.eastmoney.com/ccmx_<代码>.html` > 同花顺/雪球）。不要看名字下结论。

**已核实的"名字陷阱"实例（2026Q2）：**

| 基金 | 名字暗示 | 实际持仓 | 行业分布 |
|---|---|---|---|
| 长城全球新能源车 C 018036 | 新能源车 | 台积电/美光/博通/科磊/拉姆/闪迪/阿斯麦/谷歌/亚马逊/英伟达 | 信息技术 69.41%，美股占 74.62%，**一辆车都没有** |
| 天弘全球新能源车 C 016823 | 新能源车 | 康宁/迈威尔/美光/AMD/泰瑞达/Lumentum/应用材料/Coherent/意法/华虹 | 信息技术 **66.78%** |
| 华宝致远混合 C 008253 | 海外混合 | 闪迪/美光/拉姆/台积电/MKS/应用材料/阿斯麦/AMD/Nebius/英伟达，**另持 2.98% 半导体 3x 杠杆 ETF** | 科技 61.24% |
| 建信新兴市场 C 018147 | 新兴市场 | 台积电/英伟达/**SK海力士/三星电子**/闪迪/博通/西部数据/美光/Lumentum/康宁 | 信息技术 **70.29%**，电信 0.67%，其余全 0 |

→ **规律：带"新能源车""混合""新兴市场"等宽泛名字的 QDII 主动基金，很容易实际是"AI 硬件/半导体"基金。** 因为 QDII 可投范围窄，基金经理容易全部集中到当期最强的主线。

**第二步：建共现矩阵。** 统计每只股票出现在几只基金的前十大。**≥3 只即视为重复暴露。**

**第三步：估算单一赌注的真实规模。** 用各基金披露的行业权重（如"信息技术 66–70%"）× 市值，加上指数基金按指数成分权重折算（纳指100 半导体权重≈25%、标普500≈14%）：

```
单一主题暴露 ≈ Σ(主题基金市值 × 行业权重)
             + Σ(宽基市值 × 该主题成分权重)
```

**第四步：找跨类别隐藏重叠。** 底仓表的"资产大类"字段常错。如 **易方达亚洲半导体ETF 03486 被归为"港股资产"，重仓却是台积电/三星/SK海力士，与"美股"桶里的建信新兴市场同链**。必须跨大类查一次。

**第五步：把"买入时点 × 单笔金额"和"波动率"交叉看。** 常见病理是**金额与纪律倒挂**：对波动小的宽基只投 10–100 元/笔，对波动大的主题基金投 200–500 元/笔，且集中买在该主题暴涨之后。

**第六步：盈亏归因做反事实检验。** 算出"如果不买某一簇会怎样"。这个反事实比任何说理都有力。

**输出建议（不要建议立刻砍仓）**：
1. **零成本第一步**：修正底仓表的分类与备注，让表格说实话
2. **设硬上限**：给该主题设总资产百分比上限，之后**不再新增**该簇
3. **分季度稀释**：重复的指数基金**不卖只停新增**；浮亏的主题基金不割肉也不加码，反弹回本可借机减到 1–2 只

**为什么不建议立刻砍**：已浮亏时卖出等于"用集中度换实现亏损"；且底层资产往往是好公司——**真正的问题是"以为它是别的东西"，而不是"持有它"**。

### 5.7 额度稀缺 → 资金被从"指数"挤向"主动基金"（结构性机制）

当用户说"当时想买的指数基金额度紧张买不到，所以买了别的"时，**这几乎必然意味着他买到了主动基金**。机制：

> **QDII 额度是按产品分别审批的。** 热门指数产品额度被抢光时，冷门主题产品的额度还在。于是"买不到 A"会把人推向"买得到但完全不同的 B"。

**识别主动 QDII 的三个快速判据**（不必查合同全文）：
1. **"无跟踪标的"** —— 指数基金必有跟踪标的，主动基金没有
2. **管理费 1.20%/年 起** —— 指数 QDII 通常在 0.50%–0.80%
3. **业绩比较基准是复合指数**（如"恒生×65% + 标普500×15% + 活期×20%"）—— 说明基金经理有自由裁量权

**已核实（4 只全部为主动）**：

| 基金 | 类型 | 管理费 | 托管 | 销售服务费 | 跟踪标的 |
|---|---|---:|---:|---:|---|
| 长城全球新能源车 C 018036 | QDII-普通股票 | 1.20% | 0.20% | 0.60% | **无** |
| 天弘全球新能源车 C 016823 | QDII-普通股票 | 1.20% | 0.20% | 0.25% | **无** |
| 华宝致远混合 C 008253 | QDII-混合偏股 | 1.20% | 0.20% | 0.00% | **无** |
| 建信新兴市场 C 018147 | QDII 混合 | 1.20% | 0.20% | 0.40% | **无** |

**极端证据**：晨星资产分布显示建信新兴市场 **美国股票 37.19%、发达市场 27.76%、新兴市场 0.00%**——一只"新兴市场"基金持有 **0% 新兴市场股票**。晨星综合费率 **2.03%**（显性 1.80% + 隐性 0.23%）。

**值得对用户点出的细节**：查找"同一基金经理"往往能还原当时的决策路径。例如天弘全球新能源车（016823）与天弘纳斯达克100指数发起（018043/018044）**同属天弘、同为基金经理胡超**——"买不到的那只"和"买到的那只"出自同一人之手，只是名字不同。

**给用户的结论句式**：不要停在"费率贵"，要落在机制上——
> 额度稀缺会把你的钱从"指数"挤到"主动基金"，而主动基金的持仓可以不遵守名字的约定。这不是你选错了一只，是这个机制在系统性地这么干。

### 5.8 ⚠️ 赎回费档位**不可跨基金套用**（踩过一次）

同一家公司的 A/C/E 三类份额档位不同，**不同基金的 C 类档位也可能差很多**。给多只基金做费用测算时，**必须逐只查合同/费率页**，不能拿一只的规则套到另一只上。

**真实差异（均为 C 类）**：

| 基金 | <7天 | 7–30天 | 30–365天 | 365–730天 | ≥730天 | 归零门槛 |
|---|---:|---:|---:|---:|---:|---|
| 景顺长城纳指科技 C 017093 | 1.50% | 0.75% | 0.50% | 0.50% | 0 | **180 天** |
| 天弘全球新能源车 C 016823 | 1.50% | 0.50% | **0** | 0 | 0 | **30 天** |

**踩坑记录**：曾把景顺长城 C 类的"30–180 天 0.5%、满 180 天免"套用到上述 4 只上，得出错误的赎回费门槛结论。**不同基金的 C 类、以及同基金的 A/C 类之间均不可混用**。

**"回本再卖"这类用户计划的正确处理**：先算清卖出成本——**若成本已近零，就把讨论从"手续费"彻底转向"心理参照点"**：
1. 成本价是个人参照点，市场不知道它；卖出理由应是"仓位角色变了"
2. 对需要涨 30%+ 才回本的仓，"等回本"等于"无限期持有"
3. **给替代规则**：把条件从"回到成本价"换成可观测的配置线（如"该主题占比 ≥8% 时优先卖这一簇"）。**若标的上涨，占比会自动顶向那条线——"上涨"本身会生成卖点，用户不必盯成本价。**

## 六、上限法（约束"抢额度"导致的超配）

单一行业主题基金给硬上限 **10%**（保守）/ 15%（激进）。`天花板 = 总资产 × 上限`；`余量 = 天花板 − 现有同主题合计`。买之前先看余量——**"额度稀缺"永远不该让人超过余量**。

注意：**同一指数的多只联接基金要合并计入同一桶**（南方/万家/摩根/宝盈的纳指100 本质是同一个东西）。

## 八、输出规范

- 先给**今天 15:00 前**的具体动作，再给明天、再给结构性调整
- 涉及"要不要等"的成本对比，必须给出**两个方案的具体金额差**（几元 vs 几元），不要只说"更划算"
- 用 markdown 表格承载费率/平衡点；用 SVG 承载"缺口 vs 紧迫感"这类空间对比
- **每次引用"某类份额代码 / 某费率数字"时，注明来源类型（基金公司公告 / 晨星 / 代销平台）**——这三者可靠性不同，代销平台常有错
- 回答"要不要买"时，**必须把"能买多少"（额度/通道）和"该不该买"（配置缺口 + 纪律）分成两个答案给**——用户常把"能不能买"读成"该不该买"
- 主动给出"**到此停止优化**"的信号：当优化收益已小于该仓位单日波动时，直接说结论，不让用户在几毛钱上反复操作
- 文件写入：对同一份报告的多处修改**必须串行提交**。并行 Edit 会各自基于旧快照覆盖，导致其中一处改动静默丢失（已踩过一次）
- 结尾固定声明：信息整理与框架分析，**不构成投资建议**
