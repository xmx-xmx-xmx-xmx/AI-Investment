```python
# df 列：基金代码/基金简称/近1周…近1年/近2年/今年来/成立来（无现成排名列，自算分位）
pct = (同类近1年序列 < 该基金近1年).mean()   # 0~1，越小越差
```

## 三、两个重要发现

1. **原触发条件（跑输同类均值 ≥15pp）几乎永不触发**：14 只里 13 只优于同类中位。
   用户的"痛点基金"建信新兴市场实际近1年 +90.1%、优于同类 99% —— 之前审计的
   "跑输"印象来自**持有期收益**（买在高点），与"基金近1年跑不跑得动"是两回事。
2. **口径必须改**：同类均值是"近1年"，用户收益率是"持有期"，两者不可相减比差。
   规则 2 的判定应改为：**近1年同类分位 ≤30%（跑输 70% 同类）且持有 >180 天**。
